1. **版本差异。** 当前番茄开头与镜像存在机构名、罪名、部分情节及治疗道具差异；第10章镜像为喷雾，正版公开正文为胶囊。本文大部分剧情使用镜像版本，未声称与最新正版逐字一致。
2. **错误重复已补读。** 主镜像 order390《鬼类起源》错复 order389《无题》，第二镜像对应页也相同；另从提莫书屋获得连贯完整正文，开头与官方试读对应，详见来源补丁。
3. **异书污染已修复。** order452／标题450《假死》前段后混入另一小说，已用[小说之家同章](https://xszj.org/b/488526/c/5155731)补读。作者附言说明曾改过入地狱方式；删改前方案不并入现行规则。
4. **近重复不重复计剧情。** 第二源标题458/460、459/461内容近同。正文内还有由奈/尤奈、还魂珠/还魂丹、捕灵网/封灵网等异写；没有据此增造人物或道具。
5. **原文数据不自动修补。** 首场奖励归属及尾数、局部药剂次数等存在不齐；《证据》称现实为2027年，《沸腾》却写2026-06-29。具体原因未明，不以自行设计的时间线解释。[《证据》](https://m.xsw.tw/1760170/255980523.html)／[《沸腾》](https://m.xsw.tw/1760170/256164134.html)
6. **最新章节仍有边界。** 未获完整正文的内容不从标题、搜索摘要或同类小说经验补齐。作品仍在连载，人物推测与未解悬念可以被后续改变。

## 阅读证据如何使用

- 系统实际提示、现场行为和较可靠的旁白，与人物解释分别记录。
- 后文推翻的假说保留在对应剧情阶段，综合结论采用反转后证据。
- 系统确认死亡、失踪、幻境死亡、假死入境和复活不合并。
- NPC或派系有利益诉求时，其完整解释不自动升级为世界定理。
- 小说中的科学、历史、神话和医疗机制按虚构设定理解。
