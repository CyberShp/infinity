## 选材原则

- 区分原作事实、二手资料与同人规则（数值、授权、投影与跨体系适配均属同人规则）。
- 四类参考题型为：人造实验体／实验设施、模因丧尸、希夷式灵异、异族团战，不涉及原著后续剧情。
- 不同体系的能源（灵力、真元、查克拉、Magicka、原力、科技供能）各自独立，跨体系互通需单独适配。
- 能力的生效条件与对抗机制预先固定，满足条件即生效，不设临时免疫。
