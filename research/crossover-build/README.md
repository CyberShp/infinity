## 来源使用原则

- 现实神话／宗教资料证明文化、叙事和仪式传统，不证明现实超自然效果。游戏里的数值、授权、投影与跨世界兼容属于同人规则。
- 已有作品中存在某能力，不等于《全球死考》原文已经展示其具体商品卡。本书提供的是跨体系兑换框架。
- 本研究对古典原文、官方直接说明、原文转载、二手资料和未完成核查分别说明；不把“查到名字”写成“通读原作”。
- 不披露《全球死考》第四类副本之后的剧情。早期四类仅作题型：人造实验体／实验设施、模因丧尸、希夷式灵异、异族团战。
- 不同作品的灵力、真元、查克拉、Magicka、原力、科技能源不天然合并；适配可以购买或修习，但必须明确。
- 能力的有效条件和对抗机制事先确定。它可以强大，也可以让某一局变得容易；不能为了保持悬疑临时给敌人补免疫。
