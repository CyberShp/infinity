# Infinity

基于《全球死考：刚下刑场你让我去考试》世界观的同人文字模拟游戏项目。

玩家是一名以控制、防御、阵法与救援见长的剑修。队伍拥有自主行动的队长和主攻手；玩家在日常探索中发挥作用，也能用经营出的底牌帮助队伍扭转危局。

当前处于玩法与世界设定设计阶段。

## 设计方向

- 以探索、调查、生存和队伍协作为核心，覆盖实验设施、模因危机、规则灵异和异族团战等题型。
- 支持多主修与自选辅修，已有能力可持续深化，不锁定唯一成长路线。
- 区分原作事实、人物推测与同人改编，明确能力的生效条件与作用边界。
- 保留不同能力体系的特点，通过训练、器物与适配建立组合。
