# Infinity

基于《全球死考：刚下刑场你让我去考试》世界观的同人文字模拟游戏项目。

玩家是一名以控制、防御、阵法与救援见长的剑修。队伍拥有自主行动的队长和主攻手；玩家在日常探索中发挥作用，也能用经营出的底牌帮助队伍扭转危局。

当前可体验首考回归后的死考空间大厅，以及第一场《白雾古宅》的文字生存模拟。

## 打开游戏

浏览器打开 [主菜单](index.html)，选择「开始游戏」进入第一场《白雾古宅》的身份选择。已有考场进度时，「继续游戏」会恢复原存档。从原来的[考核页面](game/exam1_white_mist.html)进入也会看到同一个主菜单。「考场图鉴」里的「回归大厅」可以登记或打开大厅档案、探索个人房间。

主菜单支持鼠标、触屏和键盘。用 ↑ ↓ 选择，Enter 确认，Esc 关闭面板。「系统设置」可以切换动态背景和环境音。右上角可以对比两版大厅，按 A 切到即梦版，按 B 切到 Midjourney 版。初次进入显示 B 版，之后记住上次的选择。

也可以直接点大厅里的深红旋涡查看兑换光幕。这个入口不需要先建档。

B 版从考生眼前看向深红旋涡。半圆大厅里，金属天花板压低了视线，身后的十四间房留在画外。画面取空厅的一刻。初返大厅时，原著里的白光专门修复伤员。夜林伸手触碰旋涡后就能兑换能力，第 41 章还写到凝视旋涡时心神被吸引的感觉。[第31章《B级评价》](https://fanqienovel.com/reader/7630121172067156542) · [第32章《房间与兑换》](https://fanqienovel.com/reader/7630473169354097214) · [第41章《暴君血统》](https://fanqienovel.com/reader/7632481288355594777) · [第160章《战区上线》](https://fanqienovel.com/reader/7654943903212126745)

## 设计方向

- 以探索、调查、生存和队伍协作为核心，覆盖实验设施、模因危机、规则灵异和异族团战等题型。
- 支持多主修与自选辅修，已有能力可持续深化，不锁定唯一成长路线。
- 区分原作事实、人物推测与同人改编，明确能力的生效条件与作用边界。
- 保留不同能力体系的特点，通过训练、器物与适配建立组合。
