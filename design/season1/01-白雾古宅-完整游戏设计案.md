### 2. 为什么「三条真·IF 线」全部实装且绝不稀释品质？
三条 IF 线并非另起炉灶拼凑三个孤立小剧本，而是**共用同一座二进十节点物理沙盒、十份原件与六人自主状态机**，在关键物证与阵营交汇点自然长出的高光颠覆分支：
- 查水路暗闸顺手捞出河埠沉水铁匣 → 自然衍生 **IF①【账房还魂·反水弑主】**；
- 抓获沈岚怀表木屑铁证后选择“私下挟制交易”而非“向周衡举报” → 自然衍生 **IF②【黑市同盟·开棺窃玉（与周衡决裂邪道线）】**；
- 保下首夜全员＋拨开内书房鲁班匣拿到裴贼生辰八字＋缴获替死偶 → 自然衍生 **IF③【七人逆命·替死反钉真结局】**。

### 3. 跨场共用底盘与本场专属玩法三件套
- **跨场共用底盘**：四维属性（`体魄 PHY` / `敏捷 AGI` / `观察 OBS` / `意志 WIL`）、伤势与精力（`HP` / `STA`）、严格受限的 **5 格随身背囊**、自主队友状态机、死考空间漩涡大厅（60 分基础费 ＋ 躯体修复费 ＋ 跨场存档继承 `EXAM1_SAVE_PAYLOAD`）。
- **本场专属玩法三件套（零空气墙、零标黄喂饭）**：
  1. **【多页原件亲手翻验台】**：支持翻页、翻转封底、侧光查夹层、嗅闻/触摸、多原件并排对账（日期、鲁班尺门类、生辰八字全靠玩家自己比对，随身记录绝不自动归纳结论）。
