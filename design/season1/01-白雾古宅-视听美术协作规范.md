# 第一场《白雾古宅》视听、美术与特效协作规范（Codex 对接版）

> **协作定位**：本规范用于指导 **Codex** 为 `game/exam1_white_mist.html` 制作并挂载「看得见的东西」（场景背景、动态视频背景、角色立绘、画面特效）与「听得见的东西」（环境 BGM、事件 SFX）。  
> **解耦原则**：剧情文本、世界真相、数值检定与流程状态机已由 `TRUTH ENGINE 0.9` 托管，所有视听资源均通过 **`window.AV_MANIFEST`**、**`AudioDirector`** 与 **`FXDirector`** 三个标准接口接入，**Codex 无需改动任何剧情或状态机代码**。

---

## 一、标准资源目录结构

所有新增视听资源请统一放入 `game/assets/` 下（相对 `game/exam1_white_mist.html` 路径为 `assets/...`）：

```text
game/
├── exam1_white_mist.html
└── assets/
    ├── scenes/          # 场景静态图 (.webp / .jpg) 或动态循环背景 (.mp4 / .webm)
    ├── portraits/       # 6 位同行考生头像/半身立绘 (.webp / .png)
    └── audio/
        ├── bgm/         # 循环氛围音轨 (.ogg / .mp3)
        └── sfx/         # 单次触发音效 (.ogg / .mp3 / .wav)
```

## 二、场景背景清单（`AV_MANIFEST.scenes`）

### 构图与美术总要求
- **画幅与分辨率**：`16:9`（建议 `1920×1080` 或 `1600×900`），静态图优先 `.webp`（单张 ≤ 350KB），动态视频背景优先静音循环 `.mp4`/`.webm`（5~8秒无缝循环，≤ 3MB）。
- **视觉基调**：压抑湿冷的民国末年江南老宅，低饱和青灰/冷铁蓝/陈旧木褐为主；仅在明火风灯处出现微弱琥珀或诡异泛绿光；纯白死考空间则为极简高曝光无影冷白。
- **UI 安全留白**：画面左下角（拓扑地图 HUD）与右下角（腕表 HUD）会覆盖半透明暗色组件，**核心视觉焦点请尽量落在画面中上部（Y: 20%~68%）**，避免重要细节被底部 HUD 遮挡。

## 四、听觉设计清单（`AV_MANIFEST.bgm` 与 `AV_MANIFEST.sfx`）

- **格式与体积**：优先 `.ogg`（或 `.mp3`），单条 BGM ≤ 1.5MB，单条 SFX ≤ 150KB。
- **响度规范**：BGM 统一压限至 `-18 ~ -16 LUFS`（引擎默认 `volume = 0.35`）；SFX 统一 `-12 LUFS`（引擎默认 `volume = 0.65`），避免突兀炸耳。
- **无缝循环**：所有 BGM 必须做好首尾淡入淡出无缝衔接，**禁止使用廉价电子恐怖尖叫或烂俗跳吓**，走电影级低频氛围（Sub-bass Drone + 环境 Foley）。

## 五、画面特效（FX）扩展指南

引擎已内置 `FXDirector` 与基础 CSS 动效，Codex 可直接沿用或在 `<style>` / Canvas 层增强：

1. **已内置的特效钩子**：
   - `#scene-stage`：触发 `FXDirector.trigger('shake')` 时自动挂载 `.fx-shake` 屏震（已接入 22:00 撞门、夜探遇袭、撬铁闸）。
   - `.fx-lamp-glow`：屋内点亮周衡镇魂风灯时自动叠加暖琥珀/微绿火光呼吸层。
   - `.mist-reverse`：23:40 子时白雾倒流后自动将底部雾层切换为倒吸流动动画。
   - `.danger-vignette`：高危状态自动叠加猩红边缘暗角呼吸。
   - `#title-fx-canvas`：标题页 2D Canvas 粒子层（斜雨 + 流动雾团 + 血红脉动）。
2. **推荐 Codex 进阶增强方向**（均须受全局开关 `FX_ENABLED` 控制）：
   - 在 `#scene-stage` 内叠加一层轻量 `<canvas id="scene-fx-canvas">`：根据 `S.timeMin` 和 `getDangerLevel()` 动态绘制**窗角寒霜蔓延纹理**、**21:15 风灯青绿火苗微粒**、**23:40 雾气倒吸流线**。
   - 在 `exam_crisis` 阶段增加极克制的**窗纸微颤 + 门缝白雾渗入粒子**。
   - 纯白空间 `space` 阶段增加缓慢上升的极细微冷白光尘。

## 七、Codex 协作红线（必须严格遵守）

1. **严禁修改剧情逻辑与状态机**：不要改动 `initState`、`advanceTime`、`ROOM_HOTSPOTS`、`HYPOTHESES`、`crisisAction`、`escapeStepAction` 等核心玩法与文案。
2. **保持单文件降级可用**：即使在无本地 `assets/` 目录的纯单文件预览环境下，`AV_MANIFEST` 字段缺失或加载失败也绝不可抛出未捕获异常（所有 `Audio.play()` 必须带 `.catch(()=>{})`）。
3. **禁止引入未授权外链 CDN**：页面受 CSP 限制，不要引入外部字体/脚本/音频 CDN，所有资源均走本地 `assets/` 或原生 Canvas/Web Audio。
4. **HTML `onclick` 属性规范**：任何新增或调整的按钮属性中，若外层使用双引号 `onclick="..."`，内层参数必须使用单引号（如 `onclick="toggleFx()"`），严禁嵌套双引号导致点击失效。
5. **所有视听开关必须联动**：新增 Canvas 特效必须遵循 `FX_ENABLED`，新增音频必须遵循 `SFX_ENABLED`。
