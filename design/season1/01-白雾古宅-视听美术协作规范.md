## 四、【v2.0 重点返工】真实民俗拟音设计清单（`AV_MANIFEST.bgm` 与 `sfx`）

> **⚠️ 音频硬性红线（重申）**：  
> 1. **严禁提交 Python / NumPy / FFmpeg 数学波形（正弦波、锯齿波、白噪滤波）脚本生成的音频！**  
> 2. **格式统一为 `.mp3`（44.1kHz, 128~192kbps）**，确保 Chrome / Firefox / Safari / 移动端 WebKit 100% 原生解码。  
> 3. **音源必须为真实 Foley 拟音采样或实录级声学模型输出**，大量留白，杜绝持续刺耳底噪。
