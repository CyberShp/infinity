## 三、多血统融合与跨体系合成规则

### 1. 同级双血统融合（对齐原著尺度）
- **双 D 融合**：需两项已持有或同购的 D 级血统 ＋ **30 分 ＋ C 评价** → 合成 1 项定制 **C 级血统**。
- **双 C 融合**：需两项 C 级血统 ＋ **90 分 ＋ B 评价** → 合成 1 项定制 **B 级血统**（原著标杆：夜林融合 `C 暴君实验体 + C 观察者`）。
- **双 B 融合**：需两项 B 级血统 ＋ **270 分 ＋ A 评价** → 合成 1 项定制 **A 级血统**。
- **双 A 融合**：需两项 A 级血统 ＋ **500 分 ＋ S 评价** → 合成 1 项定制 **S 级血统**（第一季极难凑齐，通常留待终局或第二季）。

### 2. 融合三段结算原则
每次血统融合按 **「主干体格／核心能力 ＋ 制衡／增幅特性 ＋ 残留隐患」** 结算：
1. **以毒攻毒（制衡型）**：用高意志／稳心血统压制失控型血统（如 `C 暴君实验体 + C 观察者`；`C 将臣残血 + C 道门守心体`）。
2. **属性互补（质变型）**：不同维度叠加产生新机制（如 `C 剑骨雏形 + C 游魂灵体 → B 承影灵剑体`；`B 修仙者 + B 灵能黑客 → A 阵算一体道躯`）。
3. **冲突处理**：争夺同一器官、基因链或灵魂结构的两项血统无法直接叠加，必须额外支付融合费用由空间重构，或改用「外置载体／器物承载」绕开身体冲突。
