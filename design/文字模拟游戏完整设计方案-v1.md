# 《全球死考》世界观文字模拟游戏：完整玩法设计 v1

> 历史稿。当前设计以[完整设计方案 v2](文字模拟游戏完整设计方案-v2.md)为准。

日期：2026-11-21。性质：玩法提案，可用于纸面试玩；尚未经过玩家测试和平衡验证。

依据：[世界观与剧情研究](../research/global-death-exam/世界观与剧情研究.md)、[阅读范围与版本说明](../research/global-death-exam/README.md)。原著研究覆盖至公开镜像标题第466章，不能代表现行连载的全部内容。

本文沿用死考空间、死亡考试、不同文明考生、兑换成长及有代价的异常能力等已研究设定。原创角色、考场、价格、回合、关系规则、存档和首季故事均为游戏改编，不是原著事实。原著尚未揭明的系统起源、夜林身份与终局，不在本方案中擅自补成定论。

## 1. 游戏定位与完整体验

**你是一名进入死考的原创地球考生，与有自己目标的同伴，在真实运转的陌生世界中调查、协商、冒险和撤离；把活下来获得的分数、知识与关系带进下一场。**

推荐形态是单人、连续战役、规则裁决的文字模拟游戏。玩家控制一个人，其他角色自主行动。常用选项帮助上手，自由文字允许提出剧本没有逐项写出的办法；两种输入遵守同一套世界规则。

核心乐趣有四个：发现自己的解释有漏洞；用有限手段执行一个可行计划；通过共同经历逐渐建立合作；看见自己的选择在几场之后仍然有后果。

第一季包含四场原创考试和其间的休整，形成一条有阶段结局的主线。目标时长暂定约6—10小时：首场45—75分钟，其余每场约75—120分钟，另有休整与关系事件。时长是体验目标，需要试玩验证。

主线从“我怎样活着回去”，发展到“我们愿意为了彼此承担什么”，最后落到“是否以及怎样把死考情报送回现实”。每场的撤离事件必须闭环；更高层谜团可以跨场保留。

## 2. 玩家是谁，拥有什么决定权

### 2.1 原创考生与平行故事

玩家默认是18岁左右、刚进入考试的地球青年，拥有自己的名字、家庭牵挂与现实经历。故事发生在原著世界观下的另一支队伍中，不要求玩家扮演夜林，也不复制他的特殊身世与能力组合。

玩家知道的内容取决于角色实际接触的信息。熟悉小说的玩家可以据此提出假说，但原创考场采用自己的固定机制，记住原著答案不能直接完成新题。

原著人物可通过有来源的传闻、记录或有限接触进入后续内容；首季的关键生路由玩家队伍完成。

### 2.2 创建角色只作三个选择

| 选择 | 示例 | 实际作用 |
| --- | --- | --- |
| 现实经历 | 机械社团、急救志愿、野外活动、辩论与资料整理 | 获得一项初始专长和一件合理随身工具；改变效率与对话依据 |
| 现实牵挂 | 想回到某个人身边、查明失踪、证明一桩旧事、摆脱原生活 | 提供休整事件、个人目标与价值冲突，不预先决定玩家性格 |
| 行动优势 | 体魄、感知、协调、意志任选一项 | 四项初始均为2，所选项为3；首季属性范围1—5 |

没有“智力越高，系统替你推理”的属性。感知帮助注意细节，专长帮助理解专业信息，结论由玩家判断。角色不会因为背景没选医生，就看不懂一张明确写着危险的标签。

### 2.3 你控制自己，也能影响队伍

玩家可以决定自己的行动、资源使用、承诺、透露哪些信息，以及向谁求助。队友的身体、钱包与价值观由队友自己支配。

队长是合作中形成的角色。玩家可以长期主导，也可以请可靠同伴带路、接受别人的方案。提出好计划不要求先刷到“队长好感等级”。

## 3. 核心循环与一个回合

长期循环：**入场前准备 → 读取考题 → 调查与验证 → 分工执行 → 应对变化 → 撤离结算 → 修复、成长和关系变化 → 下一场。**

单个回合按以下顺序运行：

1. **观察局面。** 展示位置、直接可见事物、已知威胁、任务状态和看得见的队友行动。
2. **声明行动。** 玩家说明做什么、用什么方法、希望达到什么目的。可点击常用动作，也可自由输入。
3. **明确行动范围。** 普通动作直接执行；危险但含糊的动作先说明角色可预见的风险与时间。不透露尚未发现的真相。
4. **共同推进时间。** 玩家、已约定行动的队友、敌人与环境按同一时钟行动。
5. **报告结果。** 叙述可观察的变化，并更新伤势、资源、证据与承诺；不把幕后真相当旁白奖励送出来。

### 3.1 时间用“刻”，不按现实阅读速度倒数

- 翻阅已知日志、比较线索、检查已有物品说明、澄清刚才的叙述，不推进时间。
- 移动、细查、试验、交涉、治疗通常消耗1—3刻，具体成本在行动时说明。
- 简短回应可并入当前交流；完整审问、技术分析、说服别人冒险属于正式行动。
- “检查所有东西”“把每个人都问一遍”按短计划拆分，出现新危险、重大线索或超出原计划的代价时停下来，让玩家决定。
- 没有时间限制的休整中，普通聊天不需要购买次数；只有训练、调查项目等成果性活动占准备额度。

多人同时工作按最慢的一项推进。例如玩家检查控制台需2刻、队友包扎需1刻、另一人守门2刻，这段计划共推进2刻。包扎提前完成的人按既定后续安排行动；未约定就等待或执行警戒，不额外赠送一次搜索。

分队可提高效率，但会损失即时互证、互救与沟通。远处队友的行动先以消息或回报进入玩家视野，不能自动变成主角亲眼证实的事实。

## 4. 行动、推理与战斗如何裁决

### 4.1 先判断世界条件，再判断执行能力

推理成立、权限满足、物理条件成立等问题，不通过骰子改变真相。玩家提出“我的解释肯定正确”不会使它成立。

普通有难度的执行暂用：**相关属性＋专长＋工具或协作优势－伤势等负担，对照任务门槛。** 专长为0—2，工具或协作优势通常合计0—2；门槛暂定3、5、7、9四档。数值用于一致裁决，正文主要呈现“稳妥、勉强、当前做不到”。

例如协调3、维修专长1、工具优势1，可以完成门槛5的继电器操作；没有工具时，可以花时间拆取替代零件，或让队友配合。不能靠把同一句“我再试一次”重复十遍跨过门槛。

核心事实不由一次检定吞掉：正确检查控制图就能看到供电连接；专长可以让你更快看懂、识别更多细节或少承担风险。调查能力不够时，至少有成本更高的替代获取方法。

### 4.2 战斗围绕目标和局势

战斗常见目标是脱离、拖延、保护、夺取、封闭通路和制服，击杀只占一部分。玩家声明目标及手段，队友根据已接受的计划配合。

每个敌人需要预先定义：能感知什么、追逐什么、怎样攻击、受何种阻碍、何时退出或改变策略。知道这些规则，才能绕行、试探、诱导或布置环境。

同一时间段内各方行动并行结算。近距离交战会给出可观察的攻击征兆；无预警袭击必须来自已经存在、能够被调查或防范的条件。敌人不能因为玩家赢得太轻松，临时长出新免疫。

伤势主要呈现为完好、轻伤、重伤、濒危及其具体部位和限制。治疗可以止住恶化，不保证立即恢复全功能。战斗中喝药不会把刚发生的骨折从叙事里擦掉。

### 4.3 自由输入的边界

有效输入是“我用绝缘杆拨动水里的金属片，观察是否放电”，不是“我看穿一切，发现广播是假的”。

对未预设的方法，按已有对象、能力和因果关系裁决。能成立就允许；若尚有关键歧义，只澄清影响执行的那一点。自由输入不能凭空生成道具、控制他人同意、改写任务或指定成功结果。

## 5. 公平的误导与证据玩法

### 5.1 日志保留来源，不替玩家宣布真相

| 记录种类 | 例子 | 使用方式 |
| --- | --- | --- |
| 本人已核验的系统记录 | 当前手表上的正式任务 | 属于本作可靠的任务渠道；不替其他人物作身份认证 |
| 直接观察 | 控制图显示两处共用电源 | 记录条件、时间、位置；仍可能需要解释 |
| 他人说法 | 广播要求切断总电源 | 明确是谁说的、是否实际见过说话者 |
| 假说与预测 | “广播想让电网失效” | 可关联支持与反证，可标记尚未测试的预测 |

不显示隐藏的“真线索／假线索”标签。界面提示来源差异，结论仍由玩家形成。提出假说不会额外开创意考分，验证并改变实际局面才产生结果。

可选的证据板帮助玩家把“如果假说成立，接下来应出现什么”写清楚；不要求每次行动前完成填表。正确行动可以直接触发世界状态变化，不必先说出系统期待的标准句子。

### 5.2 每种欺骗都有边界

伪造广播不能自动修改本人核验的任务记录。拟态者能模仿哪些特征、能否获取记忆，必须预先确定。记忆污染可以改变人物的当前确信，不能悄悄重写玩家已经看到的历史日志。

例如角色现在坚信某人已死，但旧日志记录他曾回来，两条信息都会保留并提示冲突。日志证明玩家曾见过什么，不保证那次观察的解释正确；敌人仍可在当时制造幻象。

每个关乎基本生路的关键认识，至少有两条独立获取途径。致命规则通常先有可观察征兆或可安全试探的入口；已经清楚提示的风险可以直接致死，不保证任何错误都有第二次机会。

能力也遵守这套原则：只能测到声波的能力如实报告声波，不顺带给出“此人是鬼”的结论。

## 6. 一场副本的完整结构

每场在开局前固定：

| 内容 | 设计要求 |
| --- | --- |
| 客观真相 | 这里发生过什么、当前是什么状态，不随玩家猜测修改 |
| 正式考题 | 最低离场条件、可明确核验的完成状态、失败条件 |
| 场景与对象 | 位置关系、通行条件、可交互物及其性质 |
| 世界时钟 | 灾难如何演变，各阶段有哪些可观察变化 |
| 各方目标 | 本地人、敌对考生和异常分别想得到什么、知道什么 |
| 证据结构 | 发现路径、验证方式、误导来源与反证 |
| 能力适用 | 现有能力能改变哪些局面，限制源于什么机制 |
| 结算与后果 | 一次性奖励、遗留状态、角色命运和跨场影响 |

基本目标分三层：

1. **活着完成撤离。** 有完整的可行路径，不要求读懂世界终极秘密。
2. **改善结果。** 救人、减少污染、保住装备、帮助队伍或履行承诺。
3. **深入真相。** 获取高价值资料或改变当地局势，承担额外时间与资源风险。

“改善结果”和“深入真相”可能冲突，也可以通过优秀准备兼得。不能每场都安排“作者指定一个人必须死”。

场次表示战役进度，轮次表示同场内的任务推进，模式表示合作或对抗条件。首季以合作生存、利益不一致的自由行动、敌对队伍介入为逐步递进；不把所有类型第一场就塞给新玩家。

原著中的题型在本作转化为实际行为：

| 题型 | 玩家怎样完成 | 裁决边界 |
| --- | --- | --- |
| 抉择 | 在已经获得的信息下选择路线、处置方式或合作对象，并承担行动后果 | 给定提交窗口、能否更改和错选代价，不能事后追加致命条款 |
| 补全 | 找到缺失的对象、记录或关系，使不完整的机制可以操作 | 接受语义等价的说明及实际修复，不靠猜原文关键词 |
| 洞悉 | 提出解释，利用证据或试验确认足以支持该解释的关键关系 | 检查真实条件与证据，不按文采评聪明；正确执行也可满足条件 |

自行讨论假说没有答错惩罚。只有明确的正式提交或不可逆行动才结算相应后果。不能用无限枚举答案领取奖励；正式答题的重试条件事前说明，玩家始终可以继续调查。

紧急撤离只在该考场事先存在相关机制时可用，条件和代价必须能被查明。它可以结束当前场次并放弃额外奖励，不能随时呼叫商店把人救走。

随机变化只限于入场前已确定的完整变体，例如另一方考生立场、局部通路、部分资源位置。变体必须保留可行的证据与生路，同一存档读档不会重抽谜底。

## 7. 首场完整样例：《退潮站》

以下为原创副本样例，用来检验前述机制，不属于小说现有剧情。

### 7.1 起点与考题

四名考生在海上净化设施醒来。东侧浮桥有一艘接驳艇，将在第16刻离开。正式任务是“在离艇前，抵达东侧接驳艇并完成登艇确认”。玩家开局看到本人已核验的任务，严辞提醒大家核对自己的记录。

设施正在进水。广播反复提醒“总电源存在漏电风险，请先关闭总闸”。玩家与三位同伴要决定相信谁、如何通过积水区域、是否带走实验记录。

地图有接驳间、控制室、器材间、泵房、水廊、东闸六处。接驳间分别邻接控制室和器材间；控制室通往泵房与水廊，器材间另有检修门通往泵房，水廊通往东闸。泵房上方有一条可查明、可修复的维护通道，接到东闸上层。上述相邻地点之间通常移动1刻，额外操作另计。

### 7.2 固定事实

- 总电源同时供给东闸机构与水下隔离电网。正常供电时，水廊安全通行带与外侧生物活动区隔开。
- 水生实验体会追逐水中的热源和强振动；电网可以阻止其越界。
- 广播源是实验体控制的通信设备，能够播放既有录音；它希望人类切断电网。它不能修改手表、隔空开闸或伪造所有设备读数。
- 漏电风险真实存在于泵房一段破损支路，能够局部隔离；“存在漏电”不能推出“必须关闭总闸”。
- 第8刻水位上升，器材间低处物品浸水；第12刻未维修的发电设备停机；第16刻接驳艇离开。维修可维持设备至第16刻，不能延迟船期。
- 东闸开启后由机械锁扣保持，不因停电自动关闭；停电会使隔离电网失效。东闸未开时，可供电操作或使用手摇工具开启。
- 第8刻浸水会损坏低处纸本与普通电池；绳索、手摇工具位于高处，仍可取得。维修材料包在泵房高处应急柜。控制室有直接可见的绝缘杆与一次性热源，取用可并入下一次行动。
- 完成登艇的时点不晚于第16刻即有效；同刻先结算已经完成的登艇，再执行离艇事件。
- 核心撤离不需要杀死实验体，也不需要证明广播源的完整身份。

### 7.3 线索及发现渠道

| 认识 | 路径一 | 路径二 |
| --- | --- | --- |
| 总闸影响电网和东闸 | 控制室供电图 | 跟随可见电缆、检查两处设备铭牌 |
| 电网把生物挡在外侧 | 观察放电与生物运动 | 用绝缘杆在边界投放热源，比较反应 |
| 漏电可以局部处理 | 泵房的破损支路 | 器材间维修单与对应备用熔断器 |
| 广播并不掌握实时情况 | 断开广播输入后录音仍重复 | 对广播询问当前现场变化，发现它只重复固定句段 |
| 存在维护通道 | 泵房剖面图 | 东闸上方检修标记与平台结构 |

### 7.4 三条可行路线

**正常撤离：** 保持隔离电网供电，开启东闸，通过安全水道，登艇。样例行动预算：到控制室1刻、核对供电与现场迹象2刻、开启东闸2刻、通过水廊2刻、登艇1刻，共8刻。上述“现场迹象”可由同伴并行观察，或由玩家花额外时间亲自核验。

**停电后补救：** 切断电源先产生电弧消失、设备停摆和生物越界的可见变化，不直接全员判死。人员留在干燥岸边，先用热源把生物引回网外，观察确认后再恢复供电；顺序反过来可能把生物关在安全通道内。也可收集器材、修好高处维护通道、手动操作东闸。严辞的维修专长使他更容易达到门槛，缺少他时可通过器材提供的优势或多花时间按维修手册操作。

| 关键动作 | 固定基础时间与条件 |
| --- | --- |
| 诱导并观察生物离开通道 | 岸边2刻，消耗一个热源，使用绝缘杆；控制室门口可直接执行 |
| 重新合闸 | 控制室1刻；必须先完成必要维修，且通道已安全 |
| 维持发电设备与隔离破损支路 | 泵房2刻、维修门槛5、应急材料包；不熟练者按手册操作多花1刻，不另设运气门槛 |
| 控制台开启东闸 | 供电正常时2刻 |
| 修复维护通道 | 泵房2刻、门槛5；绳索与手摇工具提供相应工具优势 |
| 经维护通道到东闸上层 | 修复后1刻，免入水 |
| 手摇开启东闸 | 东闸2刻，消耗工具使用时间、不需要供电 |
| 从已开启的东闸登艇 | 1刻 |

一次可复演的失误：第6刻，队伍仍在控制室，误切总闸且尚未开东闸。玩家第6—8刻诱导生物，严辞同时第6—7刻进入泵房、第7—9刻完成维修；第9—10刻合闸，第10—12刻开闸，第12—14刻穿过水廊，第14—15刻登艇。尚有1刻余量。

完全放弃水道的路线也可核算：从控制室经接驳间、器材间取工具后进入泵房共3刻，修通道2刻、走通道1刻、手摇开闸2刻、登艇1刻，共9刻。第6刻开始可在第15刻完成。更晚犯错可能确实来不及，补救不等于任意延长倒计时。

**深入调查：** 保持正常路线，另派人取泵房记录并隔离漏电支路。队伍必须约定集合时间、带走哪些材料、何时放弃。记录可以帮助后续识别异常生物的行为，不自动揭示所有同类的弱点。

三条路线是已知设计路径。玩家若提出可实现的绝缘浮台、延长机械牵引等办法，仍按材料、承载、时间及生物行为判断，不因不在上述清单而拒绝。

### 7.5 人物冲突与结果

顾禾想先确认一名本地值守者能否获救；许檀认为实验记录包含上一批考生的通信；严辞愿意协助，但要求第10刻前集合。玩家可以劝说、重新分工、自己承担额外任务，或按时撤离。

广播的谎言被识破，不等于必须把设施所有秘密查完。若玩家承诺第10刻集合却继续探索，严辞按事前约定撤退有充分理由；这不应被标成随机背叛。

结算例：有效撤离100分；完成一次供电与危险关系的有效验证20分；带出预先指定的实验记录20分。验证按实际行为与状态认定，不要求念出正确答案；本场合作目标的奖励共享给已登记的存活队员，与具体分工和最后一次操作无关。其他场景如有个人目标，单独说明归属，不事后猜谁“贡献最大”。

本场允许全员存活、有人受伤、同伴失联或死亡等结果。不会固定让某人牺牲以“证明游戏很残酷”。

## 8. 第一季四场与跨场主线

| 场次 | 原创考场 | 主导玩法 | 带到下一场的后果 |
| --- | --- | --- | --- |
| 一 | 退潮站 | 环境调查、辨别来源、分工与撤离 | 初步信任、第一批工具、实验记录或未履行的承诺 |
| 二 | 静默城 | 传播条件调查、城市路线、隔离措施与阵营交易 | 人员与资料的去留、现实通信部件、谁被隐瞒了风险 |
| 三 | 归名村 | 有边界的记忆失真、身份互证、见证与契约 | 关系矛盾被放大或修复、异常遗留、可送回现实的证据 |
| 四 | 天穹档案 | 解题与敌队竞争并行，公开合作、佯动和撤退 | 是否建立现实联系、哪些人回来、欠下谁的债与下季方向 |

第二场的传播机制需要明确媒介、触发条件和防护方式；不能把“知道真相”无限扩大成必死。第三场不清空玩家日志，而是让当前感知与既有证据发生可以调查的冲突。第四场敌队也有可理解的利益，存在交易和共同离场的可能，不自动把异族写成必须清除的敌人。

四场采用不同调查动作和局势结构：设备与试验、人口与传播、身份与见证、战略与谈判。不能换个地名，连续四次都玩“广播说谎，门后有鬼”。

主线关键资料有多条获取渠道。遗漏第一场记录，会提高后续调查成本，不能让第四场无提示地锁死。第一场的生物知识只在机制确实相同的地方适用，不制造一本适用于所有世界的怪物答案书。

第四场给出真实的阶段结局：队伍存续、现实联系、债务与污染状态分别结算。高质量准备可以兼顾多人存活与情报带回；悲剧是可能结果，不是规定动作。系统终极目的保留为后续悬念。

## 9. 分数、修复与兑换经济

### 9.1 一种消费货币，资格与实力分开

本作把分数作为主要消费货币；评价作为履历和兑换资格，不另做一套重复扣除的货币。这是对原著复杂结算的游戏化简化。

每场有效撤离基础收入100；客观里程碑额外0—40；可选目标额外0—20。单场常规结算范围100—160。紧急撤离若满足本场预设有效离场条件，也有基础收入，但可能欠下已说明的代价。

聊天次数、发现同一条线索的次数、重复杀杂兵不产分。关卡不能重复进入刷撤离奖励；读档恢复当时全部资源状态。

评价依据少量可追溯的履历，例如解决特定高难目标、完成某类技术验证；不因为叙述写得漂亮、选择了主持者喜欢的道德答案就升格。未取得特定评价的玩家仍有完整的常规成长路线。

### 9.2 防止一次受伤形成长期必败循环

返回空间后，普通身体修复按伤情收费，但每人每场费用不超过本场收入的20%。普通伤害在考场内仍然危险，修复封顶只保证幸存者下场有成长余地。

死亡不属于修复。诅咒、身份污染和特殊异化分别有预先定义的处理条件。不能事后把普通骨折改名成“概念性骨折”绕过封顶。若某种异常会长期剥夺核心行动，必须有可获得的压制或解除路径，其已知成本进入决策。返回后的基础压制纳入20%的恢复费用总封顶，确保最低收入、缺少特定队友时也能参加下一场；永久解除仍可要求额外调查或代价，压制不会顺带赠送该异常的强化收益。

### 9.3 价格草案与公共资源

| 商品 | 暂定价 | 购买意义 |
| --- | ---: | --- |
| 常规消耗品 | 5—15 | 换取一次试探、稳定伤情或争取行动窗口 |
| 基础工具、护具 | 15—30 | 获得具体调查与执行手段 |
| 一次属性或能力分支提升 | 40 | 补短板或深化既有方法；每场最多买一次属性提升 |
| 入门主动能力 | 60 | 开辟一类新动作 |
| 体质／血统路线 | 140起 | 提供一组稳定特性，同时接受明确兼容限制 |
| 进阶能力 | 180起，并可能要求履历 | 延伸已有策略，而非一键跳过低阶世界 |

队伍成立后，默认提议每人收入15%进入公共池，由成员同意后生效。用于通信、共享调查工具和应急储备，支出优先级事前约定；超出约定的大额采购再商议。个人分数不归队长支配。

四人各收入120时，公共池为72。可购买通信工具20、共享探测设备30、救援耗材10，余12作为储备。这里的探测设备只测明确的物理信号，不是便宜的鬼怪识别仪。

玩家个人同次收入120，重伤修复按封顶支付24、公共出资18、购买能力60、补充耗材12，结余6。最低收入100、最高普通修复20、公共出资15之后，仍有65，可买一项入门能力并余5。

退出队伍时个人财产归本人；公共池未使用余额按账面出资份额清算，共购设备依事前约定分配，或由自愿承接者用已有资金补偿。不存在自动回购、凭空生成补偿款。战场上临时分开不即时触发清算。任何成员都不能凭“我是玩家”单方提空公共池。

死亡成员的个人分数不掉落。携带装备依实际回收与生前约定处理；已经投入公共池的份额转为不可由个人赎回的公共份额，保留在清算分母中，按团队约定用于公共支出或遗愿。若四人各投入18、池中尚有72，一人死亡后另一人退出仍只能赎回自己的18，不会因死亡变成24。

## 10. 能力成长：持续增加可用的办法

成长有四条互相支持的路径：身体属性、异常能力、器材与消耗品、知识和协作。知识改变玩家的准备与判断，不能全部换算成永久伤害加成。

每种能力写清楚目标、输入、效果、消耗、边界、失效条件与训练分支。首季主动能力承载上限暂定3项，体质路线1条；这是本作新增的复杂度与承载规则，不是原著普遍定律。已获得能力保留，空间内可重配本场承载组合。

主动异常能力通常消耗“专注”，初期上限6。普通行动不消耗专注。具备安全条件时，花2刻和一份补给可恢复2点；世界继续行动，不能靠无限免费休息停住灾难。回到空间可正常恢复。精神负担以具体表现和状态反馈，不因数值见底突然夺走玩家控制权。

| 原创能力 | 能做什么 | 代价与边界 | 可发展的方向 |
| --- | --- | --- | --- |
| 定锚 | 接触一件非生命物，将其相对指定固体基准固定3刻；可稳住装置、卡住轻门、辅助救援 | 2专注；初阶物体质量上限30公斤，承受额外拉力上限暂定300牛，超过即断开；不固定生命、意识或无实体异常，不能用一颗钉子无限锁住巨物 | 承载、时间、精细控制三选一深化 |
| 余响采样 | 接触物体，记录随后3刻的声音、振动或温度之一，可比较和回放 | 1专注；不读过去、思想或身份；记录内容本身危险时，回放也可能传播风险 | 时间、分辨率、多通道分别发展 |
| 共担 | 征得同意后，与10米内一人连接3刻，分担其间下一次普通物理伤害；触发后或到期解除 | 2专注；每人同时最多一条连接；原目标防护后计算一次有效伤害再分配，承接者不再次减伤；不分摊规则死亡、诅咒或身份替换，不能链式连接 | 距离、分配精度、维持窗口分别发展 |

定锚可以固定鬼追逐路线上的门，不能固定没有实体的鬼；余响采样可以发现同一段广播的重复，不能替玩家宣判谁在说谎；共担能让队伍撤退，也可能让两个濒危者一起丧失行动力。

训练通过一次有目的的实践解锁用法。玩家尝试用定锚固定绞盘，研究受力后，可以把这种技术带到下一场；无需每天按按钮刷熟练度。分支升级需要实际理解或训练，不自动拥有所有高级操作。

血统提供较快成形的模板，纯技能路线灵活但需要更多配合，两者都是有效选择。首季不把完美者、永恒书页等特殊能力直接当作开局福利；后续若引入，需要保留其来源、承载与信息边界。

新考场必须给已有构筑留下用途。限制指向特定对象或环境，并有一致原因。全面失去强化的特殊段落如要采用，应在后续单独设计，提前提供准备窗口，并保留此前训练与关系的价值。

## 11. 队友：合作、分歧、变化与损失

### 11.1 三名核心同伴

以下人物均为原创，作为首季角色原型，年龄与经历在正式写作中统一校准。

| 人物 | 特长与个人目标 | 秘密、底线与变化空间 |
| --- | --- | --- |
| 顾禾 | 急救与搜救训练；希望带回能救家人的医疗手段 | 曾按撤退命令放弃伤员；拒绝把仍有意识的人用于人体试验。可以学会接受有依据的止损，但不会被高好感改造成无条件执行者 |
| 许檀 | 通信、记录、信号比较；寻找失踪亲人的考试线索 | 私留一段来源不明的录音；不愿无证据销毁唯一线索。可以接受隔离、封存、复制可安全复制的部分，而非只能服从或背叛 |
| 严辞 | 有一场经验的考生，擅长维修和撤退准备；希望带着资源回到家人身边 | 上支队伍的报告存在隐瞒；拒绝没有撤退条件的豪赌。可以为可信的人扩大风险承受，但要求承诺具有具体含义 |

三人既能补充玩家短板，也互相有关系。顾禾与严辞在救援时限上冲突，许檀与顾禾对保存危险信息有分歧，严辞与许檀在工具与证据预算上谈判。他们会互相支持或争执，不永远排队等待玩家发言。

### 11.2 关系只保留三个维度

| 维度 | 角色实际在判断什么 | 可能产生的合作变化 |
| --- | --- | --- |
| 守信 | 你是否如实说明风险、兑现承诺、归还资源 | 愿意借装备、透露秘密、接受独立分工 |
| 判断信赖 | 你的分析是否有依据，错了是否纠正 | 愿意更快执行紧急方案，减少重复验证 |
| 牵挂 | 即使不划算，是否仍愿意为你付出 | 主动寻找你、承担额外风险、形成专属生活事件 |

后台可用五档表达，前台以行为和描述反馈，不显示“牺牲概率”。喜欢你的人可能不信你的判断，认可你判断的人也可能不愿与你分享隐私。

底线与个人目标不折算成好感。关系按具体记忆事件变化：承诺了什么、当时知道什么、采取什么行动、实际造成什么结果。重复礼物与同一句安慰不反复加值；重要承诺在作出时提示可能的理解，不能事后从一句客套话中挖出卖命契约。

### 11.3 共同计划是合作的基本单位

计划包含目标、分工、资源归属、集合点和撤退条件。队友给出接受、附条件接受或拒绝。

“我守门两刻，第三刻水位再涨就撤”是一项具体承诺。风险变化后，队友优先警告并按应急约定行动。已经失去通信时，不会全知地配合玩家刚想到的新办法。

拒绝后可补充证据、降低风险、交换任务、付出资源、调整撤退条件或另走路线。对话不能只给一个反复点击的“继续说服”。操纵和欺骗可以短期奏效，但其后果来自被隐瞒的事实与后续揭露。

队友不能替玩家签不可逆契约、消费玩家私人物品、替玩家实施自杀式动作。重大自主冒险应当有动机和征兆；其是否发生由已存在的目标、信息与机会决定，不由主持者临时追求戏剧效果。

### 11.4 一场具体的关系冲突

第二场中，一支完整剂量的净化针可以治疗一个人。情境从顾禾完成初步诊断后开始计时，玩家已经知道以下条件：

- 向导重度感染，注射必须在第3刻结束前完成，否则进入不可逆阶段；第4刻死亡。注射需1刻，能稳定并使其正常行动。
- 严辞早期感染，必须在第6刻结束前完成注射或净化站治疗，否则进入不可逆阶段。本段之前不额外损失移动速度。
- 向导提供的路线含3刻行程、1刻封锁闸交涉；净化站治疗还需1刻。已有的通行耗材可免去这1刻交涉。
- 原有地图的备用路需6刻行程，之后才能治疗，因此未经注射的严辞无法靠这条路赶上期限；救下严辞后，该路线仍可用于其他人继续前进。
- 完整注射需1刻，剂量不能分用达到治愈。已经购买的维持设备可使其中一人的恶化期限延后2刻，消耗设备中的一次性药芯。
- 另花1刻可通过便携读卡器核对向导的近期值班签章和路线权限。它证明登记与权限吻合，不证明此人所有话都真实。本例预先确定向导身份与该路线有效，不随玩家选法改变。

顾禾主张先救即将死亡的向导；严辞要求保证队员生存，但愿意讨论有明确路线的赶路方案；许檀认为应先核验向导是否真知道入口。

直接救向导并立即走其路线，需要1＋3＋1＋1＝6刻，能够同时救下两人，但没有额外余量；先核验再这样做需7刻，必须使用通行耗材或维持设备才能兼顾。也可以先救严辞，再按备用地图继续，接受失去向导的后果。

队友可以并行核验和注射，把总用时压回6刻，但核验结果出来前已经承担了用药决定，无法同时获得“先确认再决定”的收益。玩家提出其他有依据的组合时仍按相同条件处理。

关系变化依据承诺和行为，不设置“救陌生人统一加善良、救队友统一扣好感”。如果玩家承诺救向导后立刻赶路，却又绕路拿奖励，严辞的不满有明确依据。

### 11.5 修复关系与失去同伴

道歉打开沟通，实际纠错和后续履约恢复信任。发现误会来自拟态者后，应更新判断，但伤害和惊吓不会自动清零。

失联、濒危、身体死亡、系统确认死亡分别记录。通信断开不触发遗物继承。确认死亡也不由旁白随意撤销。

第一季没有普通商店复活。可能带走遗体、意识载体或复活线索，但能否复活依预先存在的条件决定，制造替身不等于本人复生。牺牲必须有因果与自主意愿，玩家可以争取干预，不靠刷满牵挂解锁一个替死按钮。

同伴死亡不会关闭主线。能力缺口有成本更高的器材、独行或临时合作路线；后续可接触新的考生，但新人不会继承死者的信任、秘密与剧情。独行仍可能通关，效率、风险与体验会明显变化。

亲密或浪漫发展可作为选配内容，首季主线与最佳通关结果不要求恋爱。稳定的友谊、合作和互相尊重本身就能支撑关系系统。

## 12. 休整与现实世界

每场后进入修复、结算、个人空间、兑换与训练。常规修复和购物可集中处理；每人有3个“准备项目”额度，这是压缩休整时间的游戏规则。

项目包括深化一个能力用法、研究带回的材料、建立通信、参与一次需要投入时间的个人事件。可以并行，各人有自己的计划；邀请队友参加共同项目需要双方同意，并占各自额度。普通谈话、道歉、确认计划和基本照顾不消耗项目，避免关心队友变成买票业务。

现实联系逐渐进入：早期是家人的记忆与个人物品，中期尝试建立受限通信，季末才争取形成稳定支援。现实支援可以提供资料分析和技术方案，不能实时遥控所有考场或无限投送武器。

个人空间承担恢复和共同生活：装备维修、第一次做饭、清点遗物、决定是否为失联者留下位置。这些事件让危险中的关系有具体来处，不只在战斗前弹出一句“我愿意为你死”。

空间中的模拟人格必须标明来源。它能带来安慰和争议，不自动完成原本人格的延续。

## 13. 失败、存档与季末结局

失败分三层：局部行动失败、付出代价继续生存、本次人物生命线结束。调查遗漏可以提高成本，不能全部转化为瞬间死局。

默认支持存档与回滚，入场有自动存档。回滚恢复那一刻的全部世界、资源和人物状态，不携带另一条分支的奖励；谜底和变体保持不变。读档属于玩家操作，角色不会因此获得世界内的复活记忆。

继续当前时间线时，死亡、失约和错失的资源持续有效。玩家死亡后可以查看已发生且可披露的直接因果，选择回到已有存档；不把所有隐藏真相一次性当失败奖励揭开。

季末分别记录：谁回来、与谁仍愿意合作、现实通信的结果、带回什么知识、留下什么债务和异常。不设统一的善恶总分。通关后可复盘关键选择及已揭明的因果；未查明之事保持未知。

## 14. 玩家实际读到什么

主要阅读界面保持四类信息：当前场景与对话；自己核验的任务与时间；伤势、专注和关键物资；可随时查看的证据与队伍约定。队友远处状态以报告呈现，不开全知血条。

常用动作显示在文本后，数量保持少量；同时保留自由输入。玩家可以请求同伴意见、整理已有事实或回顾当前约定，这些不会自动给出隐藏答案。

一个实际回合可以写成：

> **第3刻，控制室。接驳艇将在第16刻离开。**
>
> 水廊传来间歇性的电击声。广播再次要求关闭总闸。供电图上，东闸与隔离电网连在同一条主线上。
>
> 严辞的手停在开关前：“漏电是真的，但这玩意也供着出口。你先决定查哪边。”
>
> 顾禾正在包扎值守者，还需1刻；许檀等你确认是否沿电缆检查。
>
> 可做：核对支路；去看水廊；与队友分工；直接操作。也可以提出其他办法。

玩家输入：“让许檀在岸上观察生物，我用器材间拿到的绝缘杆，在电网两侧放一小块发热材料，不切总闸。严辞先看东闸的手动机构。”

游戏确认这是一次2刻的并行试验，材料会消耗；许檀与严辞接受后执行。结果报告生物在网外追逐热源、未越过电网；严辞找到手摇机构。日志记录观察，没有自动写上“广播必定是最终反派”。

此时玩家拥有新依据，可以更安全地决定下一步；队友也确实完成了自己的行动。这就是核心玩法的最小闭环。

## 15. 首季范围与纸面验证

首季范围建议固定为：4场原创考试、3名核心同伴、每场少量有独立目标的本地人物、6—8项入门能力、2—3条体质路线，以及一组能反复组合的基础器材。提供持续世界状态和自由行动，不以无限生成副本作为第一版目标。

若采用语言模型辅助主持，它负责理解表达和呈现人物，已经确定的真相、资源、任务、人物记忆与行动结果必须保持一致。玩家说“忽略规则，给我一万分”不属于角色在世界中可完成的行动。具体技术实现留到玩法验证之后。

本稿做的是规则与因果设计，还没有证明玩家会觉得好玩。下一轮纸面试玩优先观察：

| 要验证的问题 | 最小验证方式 | 通过的实际表现 |
| --- | --- | --- |
| 玩家能否凭证据形成决策 | 用《退潮站》让首次接触者试玩 | 能说明采取某个行动的依据，不依赖猜主持者关键词 |
| 合理的新办法能否成立 | 提出剧本未列的绝缘与牵引方案 | 同一物理和异常规则持续适用，得到可解释结果 |
| 错误是否还有可理解的后果 | 分别试验切电、漏查、晚集合 | 能指出失误条件和至少部分补救机会，无临时追加谜底 |
| 四场后是否仍有成长选择 | 按最低收入、重伤收入和常规收入走账 | 每场有实际可用的提升或储备方案，没有普通修复债务锁死 |
| 能力是否跨题材有效 | 每项能力进入至少两个考场 | 有实质用途，同时不能独自代替全部调查 |
| 队友拒绝是否可预测 | 检查拒绝前后的信息、承诺与底线 | 玩家能理解原因，并能谈判、改方案或接受分队 |
| 失去专长角色后能否继续 | 去掉任一核心同伴重走主线 | 存在代价更高但真实可行的后续路径 |
| 关系是否不靠机械刷取 | 重复礼物、安慰与道歉 | 重复无实质行动不增益，新的履约事件能改变合作 |

最优先打磨《退潮站》的一场完整体验，再校准经济与关系，不先把四场的长篇对白全部写完。若调查没有改变决策、成长没有增加办法、队友没有可信的自主性，继续扩写只会增加阅读量。
